LOCKED SPECIFICATION L0 Seed: Selectivity Over Coverage — Reclaim senior engineer attention by emitting only grounded, high-confidence, evidence-backed code review findings while routing ambiguous or critical security issues to the Human-in-the-Loop (HITL) queue.

1. Non-Negotiable System Invariants (INV-1 .. INV-7)

ID Invariant Name Specification & Enforcement Mechanism
INV-1 Verify Before Parse Webhook HMAC-SHA256 verification executes on raw request bytes before JSON parsing or DB/queue calls. Return 401/403 on missing/invalid signature; return 400 Bad Request (never 500) on validly signed but malformed JSON.
INV-2 Idempotent Ingress Every webhook delivery ID (X-GitHub-Delivery) is deduplicated atomically. Retries are acknowledged (200/202) and dropped without re-running the LLM workflow graph.
INV-3 Framework Agnosticism Domain and agent logic must never import LangGraph primitives directly outside backend/orchestrator/langgraph_adapter.py. All orchestration goes through abstract WorkflowEngine (run(), resume(), get_state()).
INV-4 Immutable Audit Spine agent_events hypertable is strictly append-only enforced via SQL triggers on BEFORE UPDATE OR DELETE (row-level) and BEFORE TRUNCATE (statement-level) raising agent_events is append-only and immutable. Every webhook, LLM call, retrieval query, and gate decision emits a span.
INV-5 Dimensional Consistency EMBEDDING_DIM in backend/config.py is validated at startup and against the code_chunks.embedding schema definition (vector(1536)). Mismatches fail fast with a clear configuration error.
INV-6 Fault Isolation & Timeouts Every external I/O call and every parallel specialist node has an explicit timeout (NODE_TIMEOUT_SECONDS), exponential backoff retry, circuit breaker, and graceful fallback so a hung node never deadlocks the aggregator.
INV-7 Grounded Evidence Zero findings may be emitted or posted without a valid file_path, line_start, line_end, evidence_snippet, rationale, and calibrated confidence in [0.0, 1.0].
